# Research: LLM Structured Output for WhatsApp Format

**Date**: 2026-11-22
**Task**: 1.2
**Status**: In Progress

## Objective

Research how to instruct the AI model (Gemini) to return WhatsApp-formatted text using structured output methods, and evaluate which approach is best for our use case.

## Background

The spec requires that the LLM returns WhatsApp-formatted text directly, rather than having the WhatsApp service convert markdown to WhatsApp format. This means we need to instruct Gemini to:

1. Format text using WhatsApp's limited markdown (`*bold*`, `_italic_`, `~strikethrough~`, `` `monospace` ``)
2. Structure tool call results in WhatsApp format
3. Handle Arabic text properly
4. Split long responses appropriately

## Structured Output Methods

### Method 1: JSON Schema with `responseMimeType`

Gemini supports structured output via JSON Schema when `responseMimeType: 'application/json'` is set.

**How it works:**
```typescript
const response = await gemini.generateContent({
  model: 'gemini-3-flash',
  contents: [prompt],
  generationConfig: {
    responseMimeType: 'application/json',
    responseSchema: {
      type: 'object',
      properties: {
        messages: {
          type: 'array',
          items: { type: 'string' },
          description: 'Array of WhatsApp-formatted messages, each ≤4096 chars'
        }
      },
      required: ['messages']
    }
  }
});
```

**Pros:**
- Native Gemini support
- Type-safe response
- Easy to parse
- Can enforce structure

**Cons:**
- Requires JSON wrapping
- May not be ideal for streaming (but we're not streaming)
- Need to handle JSON parsing errors

**Example Response:**
```json
{
  "messages": [
    "*Quran 2:153* (Al-Baqarah)\n\"O you who have believed, seek help through patience and prayer...\"",
    "The Quran emphasizes patience as a means of divine support."
  ]
}
```

### Method 2: Function Calling

Gemini supports function calling where the model calls a function with structured arguments.

**How it works:**
```typescript
const formatWhatsAppResponse = {
  name: 'format_whatsapp_response',
  description: 'Format the response as WhatsApp messages',
  parameters: {
    type: 'object',
    properties: {
      messages: {
        type: 'array',
        items: { type: 'string' },
        description: 'Array of WhatsApp-formatted messages'
      }
    },
    required: ['messages']
  }
};

const response = await gemini.generateContent({
  model: 'gemini-3-flash',
  contents: [prompt],
  tools: [{ functionDeclarations: [formatWhatsAppResponse] }]
});
```

**Pros:**
- More explicit intent
- Can have multiple functions
- Better for complex interactions
- Can validate arguments

**Cons:**
- More complex setup
- Need to handle function calls
- May be overkill for simple formatting

**Example Function Call:**
```json
{
  "functionCall": {
    "name": "format_whatsapp_response",
    "args": {
      "messages": [
        "*Quran 2:153* (Al-Baqarah)\n\"O you who have believed, seek help through patience and prayer...\"",
        "The Quran emphasizes patience as a means of divine support."
      ]
    }
  }
}
```

### Method 3: Prompt Engineering (No Structured Output)

Instruct the model via prompt to return WhatsApp-formatted text directly.

**How it works:**
```
You are a helpful assistant that formats responses for WhatsApp.

FORMATTING RULES:
- Use *bold* for bold text (not **)
- Use _italic_ for italic text (not *)
- Use ~strikethrough~ for strikethrough (not ~~)
- Use `monospace` for code (not ```)
- Use • for bullet points
- Use 1. 2. 3. for numbered lists
- Keep each message under 4096 characters
- Split long responses into multiple messages

Return your response as a JSON array of strings, where each string is a WhatsApp message.
```

**Pros:**
- Simple to implement
- No special API features needed
- Works with any model
- Easy to modify

**Cons:**
- Less reliable (model may not follow instructions)
- No type safety
- Need to parse text response
- May need retry logic

**Example Response:**
```
[
  "*Quran 2:153* (Al-Baqarah)\n\"O you who have believed, seek help through patience and prayer...\"",
  "The Quran emphasizes patience as a means of divine support."
]
```

### Method 4: Hybrid Approach (Structured Output + Prompt Engineering)

Use JSON Schema for structure, but include detailed formatting instructions in the prompt.

**How it works:**
```typescript
const response = await gemini.generateContent({
  model: 'gemini-3-flash',
  contents: [{
    role: 'user',
    parts: [{
      text: `You are formatting a response for WhatsApp.

FORMATTING RULES:
- Use *bold* for bold text (not **)
- Use _italic_ for italic text (not *)
- Use ~strikethrough~ for strikethrough (not ~~)
- Use \`monospace\` for code (not \`\`\`)
- Use • for bullet points
- Use 1. 2. 3. for numbered lists
- Keep each message under 4096 characters
- Split long responses into multiple messages

Return a JSON object with a "messages" array.`
    }]
  }],
  generationConfig: {
    responseMimeType: 'application/json',
    responseSchema: {
      type: 'object',
      properties: {
        messages: {
          type: 'array',
          items: { type: 'string' },
          description: 'Array of WhatsApp-formatted messages, each ≤4096 chars'
        }
      },
      required: ['messages']
    }
  }
});
```

**Pros:**
- Best of both worlds
- Type-safe structure
- Clear instructions
- Easy to modify

**Cons:**
- Slightly more complex
- Need to balance prompt length

## Evaluation Criteria

### 1. Reliability
- How consistently does the model follow the format?
- How often does it return invalid JSON?
- How often does it ignore formatting rules?

### 2. Ease of Implementation
- How much code is needed?
- How easy is it to modify?
- How easy is it to debug?

### 3. Performance
- Does structured output add latency?
- Does it affect token usage?
- Does it work with streaming? (Not needed for this use case)

### 4. Maintainability
- How easy is it to update formatting rules?
- How easy is it to add new message types?
- How easy is it to test?

### 5. Compatibility
- Does it work with current Gemini version?
- Does it work with other LLM providers?
- Is it future-proof?

## Initial Assessment

Based on the spec requirements and codebase analysis:

### Recommended Approach: **Method 4 (Hybrid Approach)**

**Reasoning:**
1. **Reliability**: JSON Schema ensures structure, prompt engineering ensures formatting
2. **Ease of Implementation**: Similar to current streaming implementation
3. **Performance**: No significant overhead
4. **Maintainability**: Easy to update formatting rules in prompt
5. **Compatibility**: Works with current Gemini version
