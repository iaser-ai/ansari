### Assessment

#### 1. Spec Adherence
- **Dedicated Endpoints (F2)**:
  - `GET /api/v2/threads/{id}/documents` derives sources live via [`findCitableDocumentsByThread`](file:///Users/amrmohamed/repos/iaser/ansari/.builders/spir-168/apps/api/lib/db/citable-documents.ts#L156-L177) and returns `{ thread_id, messages: [{ message_id, message_index, documents }] }`.
  - `GET /api/v2/share/{id}/documents` is public and reads purely from snapshot memory, returning `{ id, messages: [{ message_index, documents }] }`.
  - Both omit messages without citable documents and return `messages: []` when none exist.
- **Index Join Key (`message_index`)**:
  - `message_index` in [`findCitableDocumentsByThread`](file:///Users/amrmohamed/repos/iaser/ansari/.builders/spir-168/apps/api/lib/db/citable-documents.ts#L167) is computed against the full thread in `created_at` order, exactly matching the indexing of `findMessagesByThread` and `createThreadSnapshot`.
- **Pre-Change Endpoints Byte-Identical**:
  - Existing thread GET and share GET routes were not modified.
  - Share GET projects only `role`, `content`, and `created_at`, so storing `documents` in `ThreadSnapshot` causes zero leakage into `GET /api/v2/share/{id}`. Pinned by pre-change fixtures in [`documents-contract-fixture.test.ts`](file:///Users/amrmohamed/repos/iaser/ansari/.builders/spir-168/apps/api/tests/documents-contract-fixture.test.ts).
- **Snapshot Isolation (C1)**:
  - Snapshot creation in [`createThreadSnapshot`](file:///Users/amrmohamed/repos/iaser/ansari/.builders/spir-168/apps/api/lib/db/shares.ts#L46-L65) calls the derivation helper once after the ownership check, copying derived blocks into `shares.content`. The public share documents route never reads `tool_calls` or `messages`.

#### 2. Code Quality & Architectural Invariants
- **Fail-Closed & Leak Prevention**:
  - Route handlers log only `{ name: e?.name, code: e?.code }` on errors to protect against database error payload leakage.
  - Derivation helper fails closed per malformed record, logging `{ messageId, reasons }` without record content.
  - The public share route is verified by a source-scan test to ensure it neither imports `citable-documents` / `threads` nor references `tool_calls`.
- **Auth & Non-Disclosure**:
  - `GET /api/v2/threads/{id}/documents` matches `GET /api/v2/threads/{id}`: missing/invalid auth returns the identical auth error; a nonexistent or foreign thread returns 404 `'Thread not found'`.
