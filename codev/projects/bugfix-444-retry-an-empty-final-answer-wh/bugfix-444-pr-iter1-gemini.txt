### Review Assessment

#### 1. Issue Resolution & Correctness
- **Root Cause**: When `gemini-4-hydrogen` terminates a turn with an empty or degenerate response and `finishReason: 'MALFORMED_RESPONSE'`, `runFacilitator` in [agent.ts](file:///Users/mwk/Development/iaser/ansari/.builders/bugfix-444/apps/api/lib/facilitator/agent.ts#L101-L105) previously skipped the empty-final retry ladder because `RETRYABLE_EMPTY_FINISH_REASONS` only included `'STOP'` and `'MALFORMED_FUNCTION_CALL'`.
- **Fix**: Adding `'MALFORMED_RESPONSE'` to `RETRYABLE_EMPTY_FINISH_REASONS` routes this transient provider completion state into the existing bounded retry ladder:
  - Rung 1: One same-model retry.
  - Rung 2: Off-Vertex Inkling fallback when configured and not a pinned-model request.
  - Non-retryable reasons (`SAFETY`, `MAX_TOKENS`, missing/unknown reasons) continue to fail fast without retries.

  ## Summary
  Fixes #444. Adds `MALFORMED_RESPONSE` to `RETRYABLE_EMPTY_FINISH_REASONS` so empty or degenerate final completions with that reason take the existing bounded empty-final retry ladder instead of failing immediately.

  ## Root Cause
  `gemini-4-hydrogen` occasionally ends a turn with zero visible text and `finishReason: 'MALFORMED_RESPONSE'` (a string value not listed in the `@google/genai` `FinishReason` enum). Because `RETRYABLE_EMPTY_FINISH_REASONS` in `apps/api/lib/facilitator/agent.ts` only contained `STOP` and `MALFORMED_FUNCTION_CALL`, `runFacilitator` bypassed the retry ladder and immediately yielded an empty-answer error.

  ## Fix
  - Added `'MALFORMED_RESPONSE'` to `RETRYABLE_EMPTY_FINISH_REASONS` in `apps/api/lib/facilitator/agent.ts`.
  - Updated comment blocks documenting the retryable finish reasons.
  - Preserved existing fast-fail behavior for `SAFETY` and `MAX_TOKENS`.

  ## Test Plan
  - Added 6 regression tests across `facilitator-empty-final.test.ts`, `facilitator-inkling-rung.test.ts`, and `facilitator-pinned-model.test.ts` covering same-model retry recovery after tool use, ladder exhaustion, Inkling escalation, and pinned-model retry bounds.
  - Verified all 6 new tests fail without the set entry and pass with it.
