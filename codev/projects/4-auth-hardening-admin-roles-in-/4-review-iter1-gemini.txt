PR_SUMMARY: |
  ## Summary
  This PR hardens the authentication and authorization model of Ansari by transitioning trust boundaries to durable, server-controlled database state and validated configuration. It fixes seven distinct authn/authz vulnerabilities identified during multi-model security reviews, including admin privilege escalation vectors, system-account pre-registration hijack risks, session-revocation flaws, and feedback IDORs.

  ## Key Changes
  - **Durable Admin & System Roles**: Added `users.is_admin` and `users.system_key` columns with system domain reservation, production startup assertions, and `scripts/grant-admin.ts` bootstrap tool.
  - **Session Revocation & Anti-Race**: Integrated per-user `session_version` checks into access and refresh token validations, ensuring password resets and logouts immediately revoke active sessions across all devices.
  - **Feedback IDOR & Oracle Fixes**: Scoped feedback queries strictly through user-owned threads with uniform error responses to eliminate thread/message existence oracles.
  - **Centralized Config & Token Helper**: Unified token pair generation through `issueTokenPair` and routed all auth secrets/expiries strictly through validated `config.ts`.
  - **Hardening & Hygiene**: Implemented constant-time comparison for leaderboard keys, updated password policies (`score >= 3`, max 128 chars), sanitized error logging, and opportunistic natural-expiry token sweeps.

  ## Test Plan
  - `npm run typecheck && npm test && npm run build` inside `backend/`.
  - Verify 569 unit/integration tests pass (including pglite tests for `session_version` invalidation, token reuse detection, and uniform anti-oracle responses).
  - Test deployment runbook order locally: apply `0003_lying_dracula.sql` migration → run `scripts/grant-admin.ts` → start backend.
