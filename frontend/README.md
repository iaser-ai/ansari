# Ansari Frontend

This directory is reserved for the Ansari frontend (the web and mobile client at
[askansari.ai](https://askansari.ai)), which is being migrated into this monorepo
by the frontend team.

Until it lands here, frontend development continues in its current repository.
The backend it talks to lives in [`../backend/`](../backend/); the API surface is
summarized in the [backend README](../backend/README.md).
